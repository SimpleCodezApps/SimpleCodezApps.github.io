- Choose WiFi or Cellular for your stream on the Go Live screen, with live status for each network
- Go Live checks that your destination is reachable over the chosen network and offers to switch if only the other one works
- Show the connection lost screen within seconds when the stream stops getting through, instead of appearing live
- Reconnecting a remote camera finds the broadcaster even after it changes WiFi networks
- Remote devices show an up-to-date WiFi and internet status
- Run shootouts from the remote control for hockey and soccer
- The remote control shows score and game changes made on the broadcaster while the broadcaster has control
- The clock controls show minutes past an hour (75:00) instead of hours, matching the scorebug
- Help updates
